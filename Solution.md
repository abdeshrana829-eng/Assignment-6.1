CSS Box Model Inspector — Assignment 6.1



Summary of What Was Built
Three Distinct Cards (Card 01, Card 02, Card 03): Each contains an <h2> heading and a <p> description, initialized with visibly different padding (16px, 28px, 40px), border (4px, 8px, 12px), margin (12px, 24px, 36px), and box-sizing values (content-box vs. border-box).

Real-Time Interactive Inspector: Click any card (or use the Card 1 / 2 / 3 tabs) to adjust width, padding, border-width, margin, and toggle between content-box and border-box.

Live Box Model Diagram & Dimension Readouts: Mirrors Chrome DevTools' color-coded box model diagram (Margin, Border, Padding, Content) alongside exact computed inner content dimensions, total rendered box size, and a side-by-side comparison table ready for inspecting and taking screenshots.
